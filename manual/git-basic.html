📖 Git入門・初回セットアップ
Gitが初めての方向けです。最初の1回だけ行う作業を説明します。
このマニュアルでは GitHub Desktop（画面操作できるアプリ）を使った方法を中心に説明します。
💡 Git簡易説明

Git は、ファイルの変更履歴を記録するツールです。「いつ・誰が・何を変えたか」が全部記録されるので、間違えても元に戻せます。

GitHub は、その履歴をインターネット上に保管・共有するサービスです。複数人が同じファイルを編集しても、変更をまとめることができます。

GitHub Desktop は、Gitの操作をコマンドを使わずに画面上のボタンで行えるアプリです。このプロジェクトでは GitHub Desktop を使って作業します。

💬 よくある例え：
Gitは「ゲームのセーブ機能」、GitHubは「クラウドにセーブする機能」、GitHub Desktopは「セーブ・送信ボタンがついた操作パネル」のようなものです。
🛠️ 事前準備（インストール確認）
1

GitHub Desktop のインストール

まだインストールしていない場合は、以下からダウンロードしてインストールします。

📥 ダウンロード
https://desktop.github.com/ からインストーラーをダウンロードして実行します。（無料・日本語対応）
💡 GitHub Desktopをインストールすると、Gitも同時にインストールされます。Gitを別途インストールする必要はありません。
2

GitHub アカウントでサインイン

GitHub Desktop を起動し、GitHubアカウントでサインインします。

🖥️ GitHub Desktop の操作手順
  1. GitHub Desktop を起動する
  2. 「Sign in to GitHub.com」 をクリック
  3. ブラウザが開くので、GitHubのユーザー名・パスワードでログイン
  4. 「Authorize desktop」をクリックして認証を完了する
3

GitHub アカウント・アクセス権の確認

  • ✓GitHubのアカウントを持っている（github.com）
  • ✓kintone-kamacho 組織のメンバーになっている（担当者に依頼）
  • ✓internal-html リポジトリへのアクセス権がある
4

エディタの確認（推奨：VS Code）

HTMLファイルの編集には Visual Studio Code（VS Code） を推奨します。GitHub Desktop からそのまま開けて便利です。

📥 まだの方は https://code.visualstudio.com/ からインストールできます。（無料）
🚀 初回セットアップ（最初の1回のみ）
1

名前・メールアドレスを設定する

コミット記録に使われる名前・メールアドレスを設定します。サインイン済みであれば、GitHub Desktop が自動で設定していることがほとんどです。

🖥️ GitHub Desktop の操作手順
  1. メニュー File → Options（Macは GitHub Desktop → Settings）を開く
  2. 「Git」 タブを選択
  3. 「Name」と「Email」にGitHubアカウントと同じ情報が入っていることを確認する
  4. 修正した場合は Save をクリック
▶ コマンドプロンプトで設定する場合（参考）
C:\> git config --global user.name "Taro Kamacho"
C:\> git config --global user.email "taro@example.com"
2

リポジトリをクローンする（ファイルを取得する）

GitHubにあるファイル一式を自分のPCにコピーします。これを 「クローン」 といいます。

🖥️ GitHub Desktop の操作手順
  1. メニュー File → Clone repository... をクリック
  2. 「GitHub.com」 タブを選択
  3. 検索欄に internal-html と入力し、kintone-kamacho / internal-html を選択
  4. 「Local path」で保存先を確認する（例：C:\Users\あなたの名前\source\）
  5. Clone をクリックして完了
✅ クローンが完了すると、指定フォルダに internal-html フォルダが作成されます。
GitHub Desktop の左上にリポジトリ名が表示されれば成功です。
▶ コマンドプロンプトでクローンする場合（参考）
C:\> cd C:\Users\あなたのユーザー名\source
C:\source> git clone https://github.com/kintone-kamacho/internal-html.git
3

VS Code でフォルダを開く

GitHub Desktop からそのままVS Codeを開けます。

🖥️ GitHub Desktop の操作手順
  1. GitHub Desktop でリポジトリが表示されている状態で
  2. メニュー Repository → Open in Visual Studio Code をクリック
💡 または 「Open in Visual Studio Code」 ボタンが画面中央に表示される場合はそれをクリックしてもOKです。
✅ セットアップ完了！ 次回からは 日常の作業手順 を参照してください。
